# TimeKit | تایم‌کیت

TimeKit یک جعبه‌ابزار استاتیک و فارسی برای ساعت، تاریخ، محاسبات زمانی و بهره‌وری شخصی است. نسخه فعلی بدون بک‌اند روی GitHub Pages اجرا می‌شود و ابزارهای اصلی را بدون ثبت‌نام در اختیار کاربر قرار می‌دهد.

## قابلیت‌های آماده

- ساعت زنده تهران با منطقه زمانی `Asia/Tehran`، تاریخ شمسی و میلادی، تغییر حالت ۱۲ و ۲۴ ساعته، کپی و تمام‌صفحه
- تاریخ امروز با روز هفته و شماره روز سال
- تبدیل شمسی و میلادی با اعتبارسنجی طول ماه و سال کبیسه
- تایمر دقیق با شروع، توقف، ادامه، بازنشانی، زمان‌های آماده و صدای پایان
- کرنومتر با ثبت دور و دقت صدم ثانیه
- شمارش معکوس نوروز بر اساس جدول لحظه‌های نجومی منتشرشده
- شمارش معکوس دلخواه با ذخیره محلی و لینک اشتراک‌گذاری
- محاسبه اختلاف دو تاریخ برحسب روز، هفته و فاصله تقویمی
- محاسبه تاریخ آینده و گذشته
- ساعت جهانی با شهرهای منتخب و شناسه‌های IANA
- پومودورو با تنظیم چرخه‌ها و ذخیره تعداد دوره‌های تکمیل‌شده
- حالت روشن و تاریک، طراحی واکنش‌گرا، ناوبری موبایل و پشتیبانی از `prefers-reduced-motion`
- متادیتای مستقل، canonical، Open Graph، داده ساختاریافته، `robots.txt` و `sitemap.xml`

## اجرای محلی

در ریشه پروژه یک سرور استاتیک اجرا کنید. باز کردن مستقیم فایل‌ها با `file://` ممکن است رفتار Clipboard یا برخی APIهای مرورگر را محدود کند.

```bash
python3 -m http.server 8080
```

سپس به `http://localhost:8080` بروید.

## انتشار در GitHub Pages

1. در تنظیمات مخزن، بخش **Pages** را باز کنید.
2. گزینه **Deploy from a branch** را انتخاب کنید.
3. شاخه `main` و پوشه `/ (root)` را انتخاب کنید.
4. آدرس پایه سایت را با مقدار canonical داخل فایل‌ها هماهنگ نگه دارید.

این پروژه به build step یا سرور اختصاصی نیاز ندارد.

## تصمیم‌های فنی مهم

- منطق تبدیل تقویم در `assets/js/core.js` قرار دارد تا ابزارهای مختلف از یک الگوریتم مشترک استفاده کنند.
- تایمر بر اساس زمان پایان واقعی کار می‌کند و به تعداد دفعات اجرای `setInterval` وابسته نیست.
- ابزارهای تاریخ برای اختلاف روزها از تاریخ UTC در ساعت صفر استفاده می‌کنند تا ساعت تابستانی باعث خطای یک‌روزه نشود.
- ابزارهای آنلاین از منطقه‌های زمانی IANA استفاده می‌کنند.
- رویداد شمارش معکوس دلخواه و آمار پومودورو فقط در مرورگر ذخیره می‌شوند.
- صفحه `focus-ai.html` عمداً تا آماده شدن واسط امن سمت سرور، رابط عمومی Gemini را فعال نمی‌کند.

## محدودیت‌های شناخته‌شده

- داده‌های تحویل سال در یک جدول استاتیک چندساله نگهداری می‌شوند و برای سال‌های پس از جدول، fallback تقویمی فعال می‌شود. برای انتشارهای سالانه بهتر است جدول با داده رسمی جدید به‌روزرسانی شود.
- اشتراک‌گذاری شمارش معکوس به پشتیبانی مرورگر از `btoa` و hash آدرس متکی است و اطلاعات رویداد را در URL قرار می‌دهد.
- سرویس داده زنده یا همگام‌سازی بین دستگاه‌ها در این نسخه وجود ندارد.
